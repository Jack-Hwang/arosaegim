# F10 화면 이동·메뉴·홈·설정

## 1. 한눈에 보기

이 기능은 (계획) 상태의 차기 기능입니다 — 화면 위쪽의 머리말(Page Navigation)·[☰ 메뉴] 패널·홈 화면·설정 화면의 로그아웃과 가족 전환 경로, 화면 가림·주행 중 제한 같은 화면 규칙을 다루는 수용 기준 23건을 정리합니다.
지금 앱의 화면 이동은 F2(주행·정차 전환)가 담당하고, 이 정본에서 이미 코드로 확인된 4건([코드 확인])은 현재 앱의 동작입니다 — 머리말·세그먼트 2건·세션 없는 정차 보류 1건·가족 코드 하나만 저장 1건.
나머지 19건((계획))은 접수 뒤 구현을 위한 수용 기준이며 아직 코드가 없습니다 — 이 문서는 구현된 것과 계획인 것을 상태 표기로 구분하고, 계획 항목을 구현된 것처럼 쓰지 않습니다.
수용 기준 23건 중 [코드 확인] 4·(계획) 19이고, (계획) 19건 가운데 17건은 확인 방법이 아직 정해지지 않았습니다(표의 없음) — 가족 전환 삭제(AC12)·PIN 5회·10분 잠김(AC13)만 확인 방법이 정해져 있습니다.

## 2. 목적과 범위

| 요소 | 내용 |
|---|---|
| 포함 | 시작·정차 화면 위쪽의 머리말(Page Navigation — 앱 아이콘·앱 이름·코스 부제), 정차 화면의 5단계 세그먼트 머리말, 세션 없을 때의 정차 전환 보류, [☰ 메뉴] 패널(홈·코스 선택·그때와 지금·설정), 홈 첫 화면(이어서 하기 카드·첫 기록 안내), 설정 화면의 로그아웃 경로·가족 전환 확인 화면, 가족 코드 화면 가림(앞 2자리·뒤 2자리), 주행 중 화면 제한(설정·가족 전환을 열지 않음) |
| 제외 | 주행·정차 화면 전환 판정 자체([F2 문서](F2_주행정차전환.md)), 세션·PIN의 저장과 거절 규칙([F6 문서](F6_가족코드PIN세션.md) — AC03·AC19는 F6의 동작을 화면 관점에서 본 것), 도착 스탬프 카드의 내용(F1 문서), 서버의 PIN 잠금 판정 자체(backend config.py·security.py — 이미 구현된 동작이며 이 기능은 화면 안내만 더한다) |
| 가정 | 메뉴 패널은 주행 중 최소 정보 원칙에 따라 주행 전환 시 닫힙니다(AC07 note). 시작 화면의 코드 입력칸은 입력 중이라 가리지 않는 기존 설계를 유지합니다(AC18 note — 화면 가림이 노출 방지 장치). 새 화면에서도 차량 시스템 프로필을 읽거나 저장하지 않습니다(AC22) |
| 경계 | 로그아웃 버튼은 지금 개발용 진단 화면에만 있어 릴리스 앱에서는 닿을 경로가 없습니다(정본 AC04·AC15 note). 지금의 로그아웃은 같은 프로세스 안의 진행 상태(TripSession의 스탬프·목표·거리·인원, CourseStartState의 코스 시작, QuizStateHolder의 퀴즈 진행)를 지우지 않으며, 가족 전환에서는 이것까지 지우는 것이 계획입니다(정본 AC12 note). 홈 화면은 지금 앱에 없습니다(정본 AC09 note — 소스 전수 검색 0건) |

| 상태 | 화면·세션·패널 | 화면(시작·정차·주행·홈·설정), 세션(가족 세션·둘러보기), 패널 열림·닫힘, 진행 중 코스 유무 — 홈·설정·패널은 (계획) 화면이 다룰 상태입니다(AC09·AC17·AC21) |

## 5. 입력→출력 예시

**머리말·세그먼트(AC01·AC02 — [코드 확인]).** 정차 화면과 시작 화면 위쪽에 앱 아이콘·앱 이름·코스 부제 머리말이 있고, 정차 화면에는 스탬프·퀴즈·그때와 지금·스탬프북·오늘의 기록 5단계가 한 줄로 보입니다 — 소스 Components.kt PageNavigationBar(114~188행), ParkedComponents.kt ParkedPageNavigationBar. 머리말 오른쪽의 부가 기능 자리는 비어 있고 여기에 [☰ 메뉴] 버튼을 두는 것이 계획입니다(AC01 note).

**세션 없는 정차 보류(AC03 — [코드 확인]).** 세션 없이 정차 상태가 수집되면 화면 전환이 없고 시작 화면(가족 코드 입력)이 유지됩니다(io: "세션 없음 + 정차 상태 수집" → "화면 전환 없음(시작 화면 유지)") — 단위 테스트 ModeRouterResolveTest "정차 상태에서 세션이 없으면 전환을 보류한다(Q28 - 시작 화면 유지)". 둘러보기 선택 뒤의 정차 전환은 [F6 문서](F6_가족코드PIN세션.md) AC07([확인])이 다룹니다.

**메뉴 패널(AC06·AC07·AC17 — (계획)).** 정차 중 [☰ 메뉴]를 누르면 화면 오른쪽에 홈·코스 선택·그때와 지금·설정 네 항목 패널이 열리고(io: "정차 중 [☰ 메뉴] 버튼 누름" → "오른쪽 패널 열림(네 항목 표시)"), 주행으로 바뀌면 패널과 메뉴 버튼이 함께 감춰집니다(io: "메뉴 패널 열림 + 주행 전환" → "패널 닫힘 + 메뉴 버튼 숨김"). 세로(1:1) 창에서는 패널이 본문 위에 겹치고 본문 폭은 그대로입니다 — 세 동작 모두 구현 전이며 예시는 정본 io입니다.

**홈 첫 화면(AC09·AC10·AC11·AC20·AC23 — (계획)).** 세션이 있고 정차 중이면 홈이 첫 화면이고, 진행 중 코스가 있으면 스탬프 진행과 다음 장소를 담은 "이어서 하기" 카드를 보여 줍니다. 지난 방문 기록이 없는 가족은 "오늘이 우리 가족의 첫 기록입니다" 한 줄로 시작합니다(AC11 note — 같은 문구를 쓰는 기존 화면의 방식), 도착으로 정차 화면이 올라올 때는 홈이 아니라 스탬프 획득 카드가 먼저입니다(io: "도착 이벤트로 정차 화면이 올라옴" → "스탬프 획득 카드(스텝 1)가 먼저 보임"). 서버에 닿지 않으면 기기 값만으로 카드를 보여 주고 오류 문구를 만들지 않습니다(io: "서버 응답 없음 + 진행 중 코스 있음" → "로컬 값으로 이어서 하기 카드 표시, 오류 문구 없음").

**가족 전환·잠김 안내(AC12·AC13·AC14 — (계획)).** [가족 전환]을 누르면(io: "[가족 전환] 누름" → "확인 화면 표시(삭제 전, 로그아웃 미실행)") 지워지는 것과 남는 것을 먼저 보여 주고, [로그아웃하고 바꾸기]를 선택해야 가족 코드·PIN·방문 기록·전송 대기 기록과 진행 중 코스·퀴즈 상태가 지워집니다(io: "가족 전환 확인 화면에서 [로그아웃하고 바꾸기] 선택" → "삭제 + 시작 화면"). 둘러보기에서는 가족 코드·PIN 대신 "이 차에 남은 방문 기록"만 지워진다고 보여 줍니다(AC16). PIN 5회 연속 오류에는(io: "같은 가족 코드로 PIN 5회 연속 오류" → "서버 429(가족 잠김) + 화면에 10분 잠김 안내") 화면의 잠김 안내가 표시되고, 서버의 5회·10분 잠금 자체는 기존 동작입니다(AC13 note).

**코드 가림·주행 제한(AC18·AC21·AC22 — (계획)).** 화면에 보이는 가족 코드는 앞 2자리와 뒤 2자리만 남기고 가운데 자리를 가립니다(시작 화면의 입력칸은 입력 중이라 가리지 않습니다 — AC18 note). 주행 중에는 설정·가족 전환 화면을 열지 않고, 차량 시스템 프로필은 읽거나 저장하지 않습니다.

## 6. 오류·예외 처리

- 세션 없는 메뉴 접근 — AC05 (계획): 패널을 열지 않고 가족 코드·PIN 입력 화면으로 안내합니다. 지금의 세션 게이트는 [F6 문서](F6_가족코드PIN세션.md) AC07([확인])이 같은 규칙을 정차 전환에 적용하고 있습니다.
- 서버 없는 홈 — AC23 (계획): 오류 문구를 만들지 않고 기기에 있는 값만으로 이어서 하기 카드를 보여 줍니다 — 기존 화면의 오류 한 줄 + 계속 진행 규칙과 같은 방향입니다(AC23 note).
- PIN 잠김 — AC13 (계획): 서버는 이미 5회·10분 잠금으로 응답하고(backend config.py 상수·security.py 판정), 현재 앱은 429를 일반 전송 실패로 흡수해 별도 안내가 없습니다([F6 문서](F6_가족코드PIN세션.md) AC14). 잠김 안내 문구와 배치는 설정·가족 전환 화면 구현 시 더해집니다.
- 주행 중 화면 제한 — AC21 (계획): 설정·가족 전환 화면을 열지 않습니다. 지금은 정차 화면이 주행 최적화를 선언하지 않아 주행 중 시스템이 가리는 것이 현재 동작입니다(AC21 note — 소스로 확인).
- 도착 장면 보호 — AC20 (계획): 홈이 도착 장면을 가로채지 않게 하는 규칙으로, 도착 시에는 스탬프 획득 카드가 먼저 보입니다(AC20 note).
