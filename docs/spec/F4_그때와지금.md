# F4 그때와 지금

## 1. 한눈에 보기

정차 화면의 "그때와 지금" 단계입니다. 과거 방문 연도('○년 전'), 오늘 인원과 그때 인원의 비교 문장, 오늘 함께 달린 거리, 첫 방문 문구, 유물 검수 메모, 사진 이름표(서버 저장)를 보여줍니다.
값을 읽지 못하면 그 줄을 통째로 숨기고 값을 지어내지 않는 것이 이 기능의 규칙입니다(AC04·AC07).
인원 비교 문장은 화면 표시까지 에뮬레이터 실측됐습니다(AC03 — [확인], 실측 화면 9). 다만 좌석 3명을 넣었을 때 1명으로 표시된 차이는 별도 과제(개발 기록 Q27)로 남아 있고, 이 불일치를 막는 응답률 50% 규칙이 새로 들어갔습니다(AC12).
수용 기준 12건 중 [확인] 1·[코드 확인] 9·(설계) 2입니다.
아직 미확인인 것: 인원 숨김(AC04)·600dp 레이아웃(AC11)은 코드 근거만 있습니다.

## 2. 목적과 범위

| 요소 | 내용 |
|---|---|
| 포함 | ThenNowResolver(연도 계산·과거 후보 중 가장 오래된 값 선택·무효 값 거부), 인원 비교 문장(PartySizeLine)과 좌석 응답률 50% 규칙(SeatCounting), 문장 접기(장소별 — 서버 prefs), 함께 달린 거리 줄, 첫 기록 문구(visit_ordinal), 유물 검수 전 메모(HeritageTimelineLine), 사진 이름표(점·얼굴 표시 없이 글자로만·최대 10명), 600dp 좌우·위아래 레이아웃 |
| 제외 | 사진 업로드·이름표 입력 자체(모바일 웹 — F7 문서), 좌석 점유 신호의 수집(PleosTripSignalProvider — 별도 과제 A5), 전체 접기(fold_all) 설정과 km 표시 문자열 포맷(정본 AC 범위에서 제외된 항목), 영수증·포인트(F8 문서), 음성 편지 카드(F5 문서) |
| 가정 | 인원은 숫자 하나만 쓰고 좌석별·사람별 정보는 저장하지 않는다(docs/ARCHITECTURE.md 7절). 유물 정보 3곳 전부가 검수 전이라 검수 메모가 시드에 들어 있다(AC09 — io에 '조성 시기는 6~7세기로 추정된다. 공식 자료로 검수 필요' 예시). 접기·이름표·과거 기록의 저장은 서버가 담당한다(F7 문서) |
| 경계 | 차량 화면은 서버 응답과 차량 신호를 읽어 표시만 합니다. 응답률 50%의 경계값(정확히 50%)은 통과시킵니다(AC12 io). 이름표는 사진 위의 점·얼굴 표시 없이 글자로만 보여줍니다(AC10) |

## 5. 입력→출력 예시

**연도 계산(AC01·AC02).** 과거 연도가 1975이고 올해가 2025면 yearsAgo=50년으로 '1975년(50년 전)'을 보여줍니다. 과거 후보가 1995·1975·2010 여럿이면 가장 오래된 1975만 '그때' 카드로 채택합니다. 반대로 과거 연도가 2030(미래)이거나 0 이하이면 null을 돌려 첫 방문 안내로 처리합니다 — 단위 테스트 ThenNowResolverTest의 네 케이스.

**인원 비교 문장(AC03).** 오늘 인원 3명·그때 인원 5명이면 '오늘은 3명이 함께 왔어요. 그때는 5명이었어요.'를 표시합니다. 문장이 화면에 나오는 것까지 실측됐습니다(개발 기록 F73·실측 화면 9). 다만 좌석 3명을 넣었을 때 1명으로 표시된 차이는 별도 과제(Q27)입니다.

**좌석 응답률(AC12).** 좌석 9석 요청에 4석만 응답(응답률 44%)이면 답이 있어도 null을 돌려 문장을 숨기고, 좌석 2석 요청에 1석 응답(정확히 50%)이면 경계값으로 통과시켜 응답한 좌석만 합산합니다 — 단위 테스트 SeatCountingTest `응답률 미달 - 9석 요청에 4석 응답이면 답이 있어도 null 이다`, `응답률 경계 - 정확히 50% 응답은 통과한다`. 이 규칙은 위 Q27 불일치의 일부만 읽힌 합산 경로를 막기 위해 들어갔습니다(개발 기록 F82).

**접기와 이름표(AC05·AC06·AC10).** 장소 접기는 POST folded-places(gj-museum) 후 재조회하면 folded=true로 문장이 숨겨지고, DELETE로 되돌리면 folded=false로 문장이 다시 표시됩니다. 이름표는 markers=[{name:'엄마'}] 등록 시 사진 아래 '함께한 사람: 엄마'로 글자만 보여줍니다 — 서버 시험 test_folded_place_add_remove, test_then_now_folded_flag, test_markers_saved_and_shown.

## 6. 오류·예외 처리

- 과거 연도가 미래이거나 0 이하이면 null을 반환해 첫 방문으로 처리합니다 — 단위 테스트 ThenNowResolverTest `nowYear보다 과거 연도가 크면 미래 과거로 보고 null을 반환한다`, `pastYear가 0 이하면 null을 반환한다`.
- 인원 값이 하나라도 없으면 PartySizeLine이 문장을 숨기고 값을 만들지 않습니다 — 소스 app/src/main/java/app/arosaegim/ui/parked/ThenNowExtras.kt(PartySizeLine — todayCount == null || thenCount == null 시 숨김), docs/ARCHITECTURE.md 6절 U11 표.
- 좌석 응답률이 50% 미달이면 일부만 읽힌 합산을 하지 않고 null로 남깁니다 — 단위 테스트 SeatCountingTest(위 5절), 개발 기록 F82(순수 함수 countOccupied·MIN_RESPONSE_RATIO=0.5).
- 함께 달린 거리가 0 이하·비정상이면 줄을 숨깁니다 — 서버 시험 test_metrics_total_trip_km_zero_without_trip_km, test_metrics_total_trip_km_dedup_same_course_run.
- 이름표가 하나도 없으면 이름표 줄을 그리지 않고, 11개째는 서버가 400 invalid_markers로 거부합니다 — 서버 시험 test_markers_limit_is_10_on_update_and_create(저장 세부는 [F7 문서](F7_가족기록서버모바일웹물려주기.md)).
- then-now 조회가 실패했던 실측 사례의 근원은 릴리스 빌드의 평문 HTTP 차단이었고(개발 기록 F71) 네트워크 보안 설정 수정으로 해소됐습니다 — 사례 기록은 [F9 문서](F9_오프라인대체구현.md) 6절.
